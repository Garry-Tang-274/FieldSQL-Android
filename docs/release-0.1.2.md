## FieldSQL 0.1.2：点表名看数据，按连接信任 CA

**手机：** 点数据源行下方的 **浏览表**，再点表名，就能看到数据行。**平板：** 先选中数据源，再点右侧 **浏览表**；正在写 SQL 时，左侧结构树中表名旁的网格按钮也能直接打开该表。已连接时，两种设备都可以从导航进入 **浏览表**。

在同一连接里切换页面，当前表、页码、筛选和未提交的草稿会保留。返回 SQL 标签时，光标、选区、编辑区滚动位置和撤销/重做也会恢复。这些是当前会话的工作状态，长期要用的查询请加入收藏。

**云数据库使用私有 CA 时，不必关闭 TLS。** 连接提示证书不受信任，可点 **导入 CA 证书**，选择 PEM 证书链或单张 DER CA，再点 **保存并重连**，应用会重试连接并打开原先选择的表列表或 SQL 工作区。若从数据源预先配置，在 **编辑连接 → TLS** 导入或更换，点 **保存** 即可。证书只对当前连接生效，仍会校验域名。阿里云 RDS MySQL 的云端证书可在实例 **数据安全性 → SSL → 下载CA证书** 获取，解压后选 `ApsaraDB-CA-Chain.pem`；自定义证书需使用管理员提供的相应 CA。[阿里云操作说明](https://help.aliyun.com/zh/rds/apsaradb-rds-for-mysql/configure-a-cloud-certificate-to-enable-ssl-encryption#1bf77be069zxo)

**安装：** 下载本次发布附件 **FieldSQL-0.1.2-arm64.apk**。数据库功能支持 64 位 ARM、Android 8.0 及以上。Android 9.0 及以上可在 **查询 → 端侧 AI** 或 **设置 → 端侧 AI** 一键下载 1.12 GB 的推荐模型，之后在设备内写、解释和修正 SQL。
